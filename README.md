# 3D Travel Map

여행 사진/영상 묶음을 실제 3D 지도 위에 시간순 여행 경로로 시각화. 순수 정적 웹앱 — 서버 없음.

## 바로 쓰기 (배포 주소)
**https://supark0403.github.io/3Dtravelmap/**
1. 홈에서 **📂 내 폴더 열기** → 로컬 `travel` 폴더 선택 (하위 폴더 1개 = 1개 여행)
2. 브라우저가 EXIF를 직접 읽어 경로 구성. 사진은 업로드되지 않고 로컬에서만 처리됨

> 영상 GPS·HEIC 미리보기는 브라우저 한계로 미지원 (영상은 시간 기준 배치, HEIC는 원본 다운로드 제공)

## 배치 규칙 (step-hold, 보간 없음)
1. EXIF(사진)에서 촬영 시간 + GPS 추출 (영상은 파일 시간, GPS 없음)
2. GPS+시간 파일 = 앵커. 경로선은 앵커끼리만 연결
3. 시간만 있는 사진은 **직전 앵커 위치에 그대로 쌓음** (경로 중간에 배치하지 않음)
4. 첫 앵커보다 이른 사진은 첫 앵커 위치에, 시간이 없으면 미배치
5. 직접지정한 위치는 새 앵커가 되어 앞뒤 사진 재배치

## 기능
- 진짜 3D 지도 (MapLibre, 키 불필요): 건물 돌출 + DEM 지형 + 지구본 뷰
- 지도 3단: 🗺 일반+3D건물 / 🛰 위성+3D건물 / ⛰ 지형(고도×2+음영)
- 재생/정지, 0.1~8x 슬라이더 + 정배속, 처음 사진으로(⏮), 홈(⌂)
- 일차별 선 색 + N일차 라벨, 일차 시작 기상+짐싸기 연출
- 구간 속도 기반 이동 아이콘: 🚶 도보/체류, 🚇 탈것, ✈️ 비행기
- GPS확정/같은장소/직접지정 배지, 사진 클릭·재생 바 스크럽, 따라가기 토글
- 📍 위치지정: GPS 없는 구간을 장소 검색(Nominatim)으로 직접 지정. GPS는 절대 안 건드리고, 브라우저에 저장 + JSON 내보내기/가져오기

## 구조
- `frontend/` : 전부. `app.js`(UI+재생), `local.js`(폴더 읽기+EXIF+경로 구성), MapLibre 3D 지도
- `travel/` : 여행 원본 폴더 (git 제외, 로컬 전용)
